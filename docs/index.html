ESPhone · Flash pelo navegador

Esta página grava a versão mais recente do firmware diretamente no seu ESP32 via USB (Web Serial). Rápido e sem instalar nada.

  1. Conecte o ESP32 por USB (cabo com dados).
  2. Clique em Instalar abaixo.
  3. Confirme a porta serial quando o navegador pedir.
  4. Aguarde a gravação terminar.
